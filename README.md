# opencode-git-statusline

OpenCode TUI plugin that renders a footer statusline with git branch state, active model, session token usage, cost, and elapsed time.

> Status: scaffolding — under active development via SDD. See engram `sdd/opencode-git-statusline/proposal` for current design.

## Slot

`home_footer` — coexists with `opencode-subagent-statusline` (which uses `sidebar_content` + `home_bottom`).
